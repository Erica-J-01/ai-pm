# AI PM Assistant for GitHub Copilot

Open the `copilot/` folder as the workspace root in VS Code to use this bundle natively.

## What Lives Here

- `.github/copilot-instructions.md` for always-on PM guidance
- `.github/skills/pm-*` for native PM skills such as `/pm-triage`
- `.github/prompts/*.prompt.md` for short alias commands such as `/triage` and `/pm`

## Use This Bundle

1. Open `copilot/` as the workspace root.
2. Start GitHub Copilot Chat.
3. Use either the short aliases, such as `/triage`, or the native skill names, such as `/pm-triage`.
