# AI PM Assistant for Amazon Kiro

Open the `kiro/` folder as the workspace root in Kiro to use this bundle natively.

## What Lives Here

- `AGENTS.md` for always-on PM guidance
- `.kiro/skills/pm-*` for native PM skills such as `/pm-triage`
- `.kiro/steering/*.md` for short alias commands such as `/triage` and `/pm`

## Use This Bundle

1. Open `kiro/` as the workspace root.
2. Start a Kiro chat session.
3. Use either the short aliases, such as `/triage`, or the native skill names, such as `/pm-triage`.
